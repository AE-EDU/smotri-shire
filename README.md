# Смотри шире

Адаптивный лонгрид «История одного снимка» по макету Figma. Шесть сцен
рассказывают историю Макса и его новых наушников.

Проект работает локально. Git-репозиторий не подключён к удалённому серверу.

Первая версия сохранена в `main`, коммит `c1d3217`. Ветка `animations` содержит
экспериментальные анимации для аудитории 10–14 лет и интерактивную проверку
снимка.

## Запуск

Нужен Node.js 20.19+ или 22.12+ и npm.

```sh
npm install
npm run dev -- --port 4173
```

Откройте http://127.0.0.1:4173. Сервер доступен только на этом компьютере.

```sh
npm run format
npm run check
npm run build
npm run preview -- --port 4174
```

Production-сборка находится в `dist/`. Ресурсы используют относительные пути,
поэтому сборку можно разместить в подкаталоге статического сервера.

## Организация

Стек повторяет подход проекта синтезатора «Сдвиг»: HTML, CSS, JavaScript с
ES-модулями, Vite и npm. React и дополнительные библиотеки анимации не
требуются.

| Файл                      | Назначение                                               |
| ------------------------- | -------------------------------------------------------- |
| `index.html`              | Семантическая разметка шести сцен и тексты обеих вкладок |
| `src/main.js`             | Инициализация поведения страницы                         |
| `src/guide.js`            | Переключение гайда и управление с клавиатуры             |
| `src/motion.js`           | Запуск и сброс эффектов по видимости блоков              |
| `src/scene-visibility.js` | Общие правила видимости и направления прокрутки          |
| `src/story-motion.js`     | Раскрытие кадра и отправка фотографии в чат              |
| `src/story-motion.css`    | Оформление и анимации сцены со снимком                   |
| `src/frame-check.js`      | Интерактивная проверка снимка в финале                   |
| `src/frame-check.css`     | Оформление задания и обрезка кадра                       |
| `src/style.css`           | Цвета, компоновка, адаптивность и анимации               |
| `src/fonts.css`           | Локальные шрифты с кириллицей                            |
| `public/images/`          | Оригинальные иллюстрации и SVG из Figma                  |
| `public/fonts/`           | WOFF2 и лицензии OFL                                     |

Prettier использует два пробела, одинарные кавычки, строки до 80 символов, без
точек с запятой и завершающих запятых. `.editorconfig` задаёт одинаковые отступы
и окончания строк.

## Адаптивность

За основу взяты макеты 1440 и 390 px. На широком экране композиция
масштабируется до ширины 1440 px. При ширине окна до 900 px сцены выстраиваются
в одну колонку с шириной до 640 px. Высота текстовых блоков может расти, если
тексту нужно больше места.

Изображения занимают место до завершения загрузки. Нижние иллюстрации
загружаются лениво, главный персонаж — с высоким приоритетом. Оба состояния
гайда участвуют в расчёте высоты карточки: переключение не сдвигает следующий
раздел.

## Сценарий движения

Эффекты запускаются, когда блок целиком входит в экран. При прокрутке вниз это
происходит после появления нижней границы, при прокрутке вверх — верхней. Если
блок выше экрана, запуск ждёт соответствующей границы. Направление входа
сохраняется до полного выхода, поэтому смена направления внутри блока не
вызывает преждевременный запуск.

Анимация сбрасывается только после полного ухода блока из видимой области и
повторяется при возвращении. Макс появляется один раз и остаётся видимым при
обратной прокрутке. На наушниках три неоновые точки: после трёх мягких миганий
они горят постоянно. Точки расположены поперёк чашки с учётом её наклона; на
мобильном размер каждой точки не меньше 3 px. При полном уходе первого блока
сбрасывается только индикация. Геометрия измеряется по неподвижным контейнерам,
поэтому движение иллюстраций не влияет на запуск. Прокрутка свободная, без
закрепления экрана и автоперелистывания.

| Элемент                | Поведение                                                |
| ---------------------- | -------------------------------------------------------- |
| Макс на первом экране  | Однократное появление за 400 мс со смещением на 12 px    |
| Индикация наушников    | Три мигания за 1800 мс, затем постоянное свечение        |
| Реплики                | Прозрачность и масштаб 96–100% за 300 мс                 |
| Снимок с картой        | Приближение за 700 мс только на десктопе                 |
| Указатель и подпись    | Прорисовка за 250 мс, затем появление за 180 мс          |
| Замок                  | Появление за 200 мс                                      |
| Вкладки гайда          | Мгновенная смена выбора, появление содержимого за 180 мс |
| Уголки финальной рамки | Появление за 300 мс                                      |

На телефоне сразу показан конечный крупный план карты. Настройка
`prefers-reduced-motion` отключает движение и показывает конечные состояния. При
её включении во время просмотра эффекты завершаются.

В ветке `animations` сцена со снимком сначала открывает рамку вокруг наушников
за 850 мс. Затем фотография уменьшается и становится бумажной карточкой
сообщения: появляется реплика и отметка отправки. Перед отправкой есть пауза в
одну секунду, чтобы рассмотреть карту в раскрытом кадре. Весь эпизод занимает
около 2,75 секунды. Повтор запускается при возвращении к сцене; отдельной кнопки
повтора у фотографии нет. Быстрый пропуск блока не запускает невидимую анимацию.
До запуска заголовок говорит «Макс хочет отправить снимок в чат», а при старте
меняется на «Макс отправил снимок в чат». При сбросе возвращается первый текст.

В финале читатель выбирает карту на том же снимке. Вокруг неё рисуется контур,
затем рамка обрезает фотографию, оставляя карту за кадром. Положение следующих
блоков не меняется. Задание поддерживает нажатие, клавиатуру, повтор и
уменьшение движения. Без JavaScript показаны снимок и пояснение к нему.

## Доступность

Страница имеет иерархию заголовков, описания содержательных изображений, ссылку
перехода к истории и видимый индикатор фокуса. Вкладки поддерживают клавиши со
стрелками, Home и End. Скрытая панель исключена из дерева доступности и порядка
фокуса. Без JavaScript доступны обе подборки советов; изображения и тексты не
скрываются.

сохранены рядом с WOFF2. Страница не обращается к внешним сервисам за шрифтами
или изображениями.
