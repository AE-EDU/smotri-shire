# Смотри шире

Адаптивный лонгрид «История одного снимка» по макету Figma. Сцены рассказывают
историю Макса и его новых наушников.

## Запуск

Нужен Node.js 20.19+ или 22.12+ и npm.

```sh
npm install
npm run dev -- --port 4173
```

Откройте http://127.0.0.1:4173.

## Организация

| Файл                      | Назначение                                      |
| ------------------------- | ----------------------------------------------- |
| `index.html`              | Семантическая разметка истории и тексты вкладок |
| `src/main.js`             | Инициализация поведения страницы                |
| `src/guide.js`            | Переключение гайда и управление с клавиатуры    |
| `src/motion.js`           | Запуск и сброс эффектов по видимости блоков     |
| `src/scene-visibility.js` | Общие правила видимости и направления прокрутки |
| `src/story-motion.js`     | Раскрытие кадра и отправка фотографии в чат     |
| `src/story-motion.css`    | Оформление и анимации сцены со снимком          |
| `src/title-dust.js`       | Превращение заголовка в частицы                 |
| `src/frame-check.js`      | Интерактивная проверка снимка в финале          |
| `src/frame-check.css`     | Оформление интерактивного задания               |
| `src/style.css`           | Цвета, компоновка, адаптивность и анимации      |
| `src/fonts.css`           | Локальные шрифты с кириллицей                   |
| `public/images/`          | Иллюстрации и SVG проекта                       |
| `public/fonts/`           | WOFF2 и лицензии OFL                            |

## Использованные нейросети

В работе использовались ИИ-инструменты OpenAI в среде Codex: для анализа
материалов, обсуждения идей, разработки и доработки кода, проверки поведения
страницы и подготовки документации.

Генерация изображений использовалась для доработки визуальных материалов.

Работа строилась поэтапно: запрос, оценка результата и уточнение по обратной
связи. Визуальной основой служили предоставленные макет и иллюстрации.

## Промпт-дизайн

Ниже приведены обобщённые формулировки запросов по этапам работы с ИИ. Они
передают задачи и последовательность уточнений, но не являются дословной
стенограммой. Частные правки объединены по смыслу.

**1. Анализ материалов и планирование**

> Изучи предоставленные материалы и макет. Выдели структуру проекта, основные
> сценарии и ограничения. Предложи последовательность работы и определи задачи
> первого этапа.

Результат: рабочий план и выбор подхода к реализации.

**2. Реализация по макету**

> Создай адаптивную страницу по макету. Сохрани визуальную иерархию, читаемость
> и характер оформления на разных экранах. Организуй код понятно и
> последовательно, учитывая устройство референсного проекта.

Результат: структура страницы, оформление и адаптивная компоновка.

**3. Анимация и повествование**

> Предложи анимационные приёмы, которые поддерживают смысл истории и подходят её
> аудитории. После выбора направления реализуй движение и уточни его темп,
> последовательность и связь с прокруткой.

Результат: анимационные сцены, доработанные по обратной связи.

**4. Взаимодействия и состояния**

> Доработай взаимодействия и состояния элементов. Согласуй тексты, визуальные
> акценты и движение с происходящим на странице. Сделай переходы понятными и
> проверь повторное прохождение сценариев.

Результат: согласованное поведение интерактивных элементов и текстов.

**5. Оптимизация**

> Проверь загрузку страницы и использование ресурсов. Оптимизируй изображения и
> работу эффектов, сохранив качество оформления и удобство просмотра на разных
> устройствах.

Результат: подготовка графики для веба и уточнение поведения эффектов.

**6. Проверка и документация**

> Проверь отображение и поведение страницы на разных экранах, доступность
> основных действий и корректность сборки. Исправь обнаруженные проблемы и
> обнови описание проекта, чтобы его было удобно запускать и развивать.

Результат: исправления после проверки и актуальная документация проекта.

### Правки после консультации с куратором

**1. Композиция и типографика**

> По замечаниям куратора пересмотри композицию и типографику страницы. Уточни
> иерархию, взаимное расположение элементов и визуальные акценты. Согласуй
> оформление блоков и проверь читаемость на разных экранах, сохранив характер
> проекта.

Результат: уточнённая визуальная иерархия и согласованное оформление страницы.

**2. Интерактивный сценарий**

> Доработай интерактивный сценарий с учётом обратной связи. Сделай призыв к
> действию заметным, а последовательность действий и результат — понятными.
> Согласуй тексты и анимацию, проверь повторное прохождение и работу на разных
> устройствах.

Результат: обновлённый интерактив с понятной обратной связью и устойчивым
поведением.
